## 📌 Overview

Welcome to the repository for my personal developer & security portfolio! 

Designed with a modern terminal/cyber aesthetic, this site showcases my academic path, technical skills, hands-on security projects, community volunteering, and certifications. Built for high performance, smooth interactions, and clear information hierarchy.

---

## ✨ Features & Sections

- **Terminal Initialization & Hero:** Interactive cyber-terminal hero section with instant status flags.
- **About & Journey:** Academic background (B.Tech in Cybersecurity at Silver Oak University), career objectives, and milestone timeline.
- **Experience & Volunteering:** Highlights active roles in the **IEEE Student Branch**, **SecureOps (CTF)**, and **AWS Cloud Club**.
- **Technical Toolkit:** Visual proficiency metrics across Programming, Cybersecurity, Networking, Cloud, and Systems.
- **Featured Projects:** Showcases active security builds including **Swift Cloak (P2P VPN)** and interactive educational games.
- **Credentials & Certifications:** Verified certifications, workshop credentials, and community achievements.
- **Direct Contact:** Quick links for downloading my resume and reaching out for internships or security collaborations.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Components:** Lucide Icons & Radix UI primitives
- **Hosting & CI/CD:** [Vercel](https://vercel.com)

## 🚀 Getting Started Locally

To run this portfolio locally on your machine:

### 1. Clone the repository
```bash
git clone [https://github.com/](https://github.com/)<your-github-username>/renisha-portfolio.git
cd renisha-portfolio
```
### Install dependencies
npm install
or
yarn install
or
pnpm install

### Start the development server
npm run dev
